# 匣记

球关节人偶的购入、尾款和出物账本。界面是简体中文。账记在这台浏览器里，可以手写，也可以把订单、众筹尾款或闲鱼截图识别后核对入账。

线上地址：<https://siriuswu1412-sudo.github.io/-/>

打开后账本是空的。示例表在 `samples/ledger.xlsx`，只在「数据 → 恢复示例账」时载入，不会自动写入。

## 本地运行

```bash
python3 -m http.server 8741
```

浏览器打开 <http://127.0.0.1:8741>。Windows 可双击 `启动.bat`。

## 账怎么算

- 支出 = 已付货款 + 邮费 + 代购费
- 回血 = 卖出金额
- 净额 = 回血 − 支出
- 状态是「已付定」或「待尾款」时，尾款算进待付，不重复算进支出

规则在浏览器里计算，可以查看、停用或另加。账目和规则都只存在这台浏览器里，导出的 Excel / JSON 不含视觉模型密钥。

中英文识别语言包不随仓库附带。第一次截图识别会从网络下载。
